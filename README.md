# MindControl

A native macOS app that visualizes codebases and document collections as an interactive 3D star-node map.

Point MindControl at a project directory and it renders files, modules, and documents as nodes in 3D space, with edges showing how they relate — imports, references, links — so you can see the shape of a project at a glance.

## Status

Early development. Not yet usable.

## Planned

- Load any local project directory
- Parse relationships between source files and documents
- Interactive 3D graph: orbit, zoom, select, focus
- Search and filter nodes
- More to come
